## 层间分界修正

- 根因：重复的上下圆角在零间距接触处形成细小凹槽，亮边与阴影采样使分界显得粗细不一。改为同长宽贴合段的连续侧面，加上由接触高度确定的柔和灰色分界；不再依赖微小凹槽的高光来分层。
- `npm test`：20 项通过；新增连续侧面、真实分界高度、跨模块不同厚度、不同长宽台阶、单片无额外线条及薄片圆角约束测试。
- Chrome 实测并下载 2000×2000 / 64 采样白底图和 1024×1024 / 16 采样透明图。通过投影实际接触位置，在正面与右侧各沿 41 个位置平均采样，测量三条线的垂直剖面。
- 2000 px 修正前亮边增亮约 7.7–24.9 灰阶；修正后增亮低于 0.7 灰阶。柔和分界变暗约 12.9–13.9 灰阶，同一面三条线的对比度差异小于 0.5 灰阶；等效线宽约 1.46–1.69 px。
- 1024 px 修正后分界变暗约 13.0–13.7 灰阶，等效线宽约 1.52–1.60 px；透明角落 alpha 为 0。两种分辨率均通过对比度、白色亮边和线宽一致性断言。
- Chrome 另行验证同长宽 4 in / 2 in 混合厚度、小尺寸顶层台阶，以及 -31° 方位角 / 28° 仰角，未出现着色器错误。
- `tests/helpers/seam-profile.js` 提供导出图的线条剖面测量；新增浏览器回归用例。本轮实际浏览器验证通过连接的 Chrome 进行，没有另起 Edge 执行全套自动浏览器测试。
- 示例：`docs/screenshots/seams.png`；修正前后原始对比保存在 `.local/qa/seams-before.png` 和 `.local/qa/seams-after.png`。
