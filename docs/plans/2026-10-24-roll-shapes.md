# 单片卷曲形态

范围：产品新增整卷、半卷平铺；沿用现有颜色、细孔、粗糙度、灯光、背景和导出流程。两种卷曲形态仅渲染一片海绵，原有平板模块配置独立保留。

交互：形态选择后显示单片展开长度、卷宽、厚度、卷芯内径。半卷额外支持平铺段长度、向左/向右伸出；两种卷曲均支持绕竖直轴旋转。长度按完整海绵计算，伸出越长，卷体越小；至少保留一圈。尺寸内部为厘米，界面支持 in/cm。

实现选择：用连续阿基米德螺线加水平切线段作为中心路径，沿路径扫掠带圆角的矩形截面。UV 按实际弧长和截面周长分布，复用原有材质。由真实包围盒拟合镜头和地面，不拼接独立圆环或圆柱。

1. 添加纯数学卷长、路径、输入约束与相关测试；验证展开长度守恒、水平相切和相邻卷层不交叉。
2. 添加扫掠网格及场景分支；验证单片、尺寸、落地、左右镜像、旋转和材质一致。
3. 添加形态选择及单片参数；保留旧配置，扩展配置导出与文件名。
4. 运行单元测试、构建；在 Chrome 检查两种形态、方向/长度变化、颜色沿用、刷新保存和真实 PNG 导出。
5. 更新本地生产构建并推送原 GitHub 仓库。

重点检查：短而厚的输入、最大伸出长度、极薄长卷、不同旋转角的取景、回到平板时原堆叠不丢失。参考图片仅用于形态判断，不替换材质或上传到仓库。
