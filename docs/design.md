# FOAM SKU 本地渲染工作台

用户已批准把 Three.js 海绵试样发展为本地可配置 App，并推送 ExpertSneeker/FOAM-SKU。先本地运行，后续远端部署由用户决定。

## 功能与边界

- React + Vite 管理界面，Three.js r180 渲染；纯前端，无账户、后端或云端图片服务。
- 延续已确认的白色细孔材质、近白顶面、柔和上缘、小圆角；多片沿 Y 轴严格对齐堆叠，间距为零。
- 每一片海绵使用独立圆角几何，上下边缘与中间接触处均应用圆角；不合并同长宽的外侧面，也不绘制人工分界线。圆角按每片自身的厚度与短边约束，保持真实外尺寸和零层间距。相同尺寸的片共享几何与材质资源，各自独立定位，保留不同长宽的台阶、现有对齐方式和真实阴影。
- 厘米为内部长度单位；每个模块独立设置英寸/厘米、长度、宽度、单片厚度、片数，支持增删和上下换序。模块 1 在底层，后续模块累计高度并贴合；整组支持居中、四边、四角共九种对齐，以整组最大长宽为基准，方向不随镜头旋转。默认居中，随 JSON 与浏览器保存；圆角、颜色、孔纹强度与尺度共用。
- 形态仅保留平板堆叠与半卷平铺。旧整卷配置迁移为伸出长度为 0 的半卷，保留单片尺寸、朝向、材质和独立堆叠设置。
- 默认参数以用户 Chrome 中的设置为基础并按后续要求调整：圆角 0.7 mm、孔纹强度 0、尺度 0.3×、整体亮度 1.02、顶部补光 0.32、64 采样。
- 默认透视相机：仰角 11°、方位角 31°、焦距 65 mm、画面占比 0.84。可拖动旋转、滚轮缩放，数值控制，复位和适合画布。
- 纯色 / 透明背景，默认透明；阴影开关、阴影浓度和柔和度、光照亮度可调。棋盘格仅用于预览，不进入 PNG。
- PNG / JPEG 导出；透明模式只允许 PNG。边长 256–4096 px，独立宽高；16/32/48/64 采样。
- JSON 版本 2 保存各模块和顺序；导入及浏览器读取兼容版本 1，保留旧存档。预设尺寸按模块独立应用，一键恢复用户确认的默认参数。
- 导出期间冻结参数并显示真实进度，可取消。错误反馈可见，GPU 不可用时保留参数并提示。
- 每个可调参数提供独立的恢复默认按钮；共用小型回转箭头、明确的可访问名称和悬停提示，按钮位于表单标签之外。模块与单片尺寸按物理尺寸恢复并保留显示单位，单位可单独重置；模块预设与分辨率预设分别恢复其组合字段。背景色与阴影的编辑控件不可用时仍可重置其存储值，导出期间所有重置按钮禁用。保留底部的全局恢复默认。
- 左侧模块卡片按顶层到最底层排列，标题按钮可独立折叠，支持键盘和明确的展开状态；规格摘要及换序、删除操作始终可见。模块移动时保留其折叠状态，新增顶层模块自动展开并滚动可见。仅反转显示列表，参数存储与渲染仍使用原有从底层到顶层的顺序。

## 界面

参考本轮 Image Gen UI 概念：白色顶栏、320 px 白色左侧参数栏、浅灰工作区、绿色主按钮，6 px 控件圆角。页签：产品、视角、场景；右侧包含实时预览和底部导出区域。中文系统字体，清晰、紧凑、无营销区块。

概念中的海绵仅为构图示意；实际材质必须使用已批准的程序化 Three.js 材质。为保证导出一致性，画布按输出宽高比显示（概念图里拉宽的画布有意调整）。移动端预览在前、参数在后，导出区域保持可达。

## 验证

单位转换 / 参数校验 / 实际几何尺寸与贴合堆叠用 Node 测试；真实浏览器验证渲染、控件、配置往返、透明 PNG、背景颜色、阴影、指定像素、移动端布局及控制台错误。对比界面概念与实际截图；导出图检查像素及 alpha。
